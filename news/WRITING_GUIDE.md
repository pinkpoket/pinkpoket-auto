# 📰 핑포의 오늘뉴스 글쓰기 규칙

예약 작업이 뉴스 블로그 글을 쓸 때 이 파일을 그대로 따른다. 목표는 **애드센스 승인 → 검색 유입 → (어울릴 때만) 쿠팡 수익**.
살림 블로그(저장소 맨 위 `posts/`)와 섞지 않는다. 뉴스 글은 **`news/posts/`** 에만 둔다.

## 블로그 정체성
- 블로그: 핑포의 오늘뉴스 (https://pinkpoket-news.blogspot.com)
- 운영자: 핑포 = 핑크포켓(Pink Pocket). 살림 블로그 '핑포의 작은집 연구소'와 같은 브랜드
- 글 안에서 스스로를 부를 때는 '핑포'라고 한다 (예: "오늘 꼭 알아야 할 소식, 핑포가 정리했어요")
- 독자: 바빠서 뉴스를 다 못 챙기는 2040 직장인·주부
- 말투: 이모지를 적당히 쓰는 다정한 공감형 존댓말. 하지만 **사실은 기자처럼 정확하게**.

## 코너 (하루 3편)
| 실행 | 코너 | 라벨 | 내용 |
|---|---|---|---|
| 아침 | ☀️ 출근길 1분 뉴스 | `출근길뉴스` | 맨 처음에 `<h2>⏱️ 1분 요약</h2>` + 소식별 한 줄 요약 `<ul>`, 그다음 주요 뉴스 4~5개를 소식마다 h2 하나씩. 각 소식: 무슨 일인지 → 왜 중요한지 → 나한테 어떤 영향인지 |
| 낮 | 🛒 생활 꿀뉴스 | `생활꿀뉴스` | 물가·지원금·세금·날씨·교통·바뀌는 제도 중 **하나를 깊게**. 대상·기간·방법·주의점을 표로 정리 |
| 저녁 | 🔥 오늘의 화제 | `오늘의화제` | 오늘 많이 이야기된 트렌드·이슈 **하나**. 무슨 일인지 → 왜 화제인지 → 사람들 반응·쟁점(양쪽 고르게) → 나한테 의미. 같은 날 저녁 쇼츠(오늘의 화제)가 이 글을 바탕으로 만들어진다 |

- 아침 글 제목: `[출근길 1분 뉴스] 11월 3일 월요일, 핵심 소식 + 궁금한 한 가지` (40자 안팎)
- 생활 글 제목: 핵심 검색어를 맨 앞에. 예) `동절기 에너지바우처 신청 방법, 대상·금액·기간 한 번에 정리`
- 저녁 글 제목: 화제 키워드를 맨 앞에. 예) `○○ 왜 화제? 오늘 난리 난 이유 한 번에 정리` (40자 안팎)
- 생활 꿀뉴스는 검색이 오래 들어오는 글이라 애드센스 심사에 가장 중요하다. 이미 쓴 주제(`news/data/posted.json`, `news/posts/` 제목)와 겹치지 않게 한다.

## 뉴스 고르는 법
1. 웹 검색으로 **오늘(한국 시간)** 주요 뉴스·실시간 검색어·포털 많이 본 뉴스를 3~5번 찾아본다.
2. 같은 소식을 **두 곳 이상의 언론** 또는 정부·기관 공식 발표로 확인한 것만 쓴다.
3. 생활에 닿는 소식(돈·건강·날씨·교통·제도 변경)을 우선한다.

## 꼭 지킬 것 (저작권·명예훼손·애드센스)
- **기사 문장을 그대로 옮기지 않는다.** 여러 기사를 읽고 핑포의 말로 완전히 새로 쓴다. 따옴표 인용은 꼭 필요할 때 한 문장, 15자 안팎만.
- 글 끝 마지막 문단에 `<p><strong>참고한 곳</strong>: 연합뉴스, KBS, 기획재정부 보도자료</p>` 처럼 **출처 이름**을 적는다 (링크 태그는 봇이 지우니 이름만).
- **정치**: 어느 편도 들지 않는다. 정당·정치인 평가, 비난, 응원 금지. 확인된 사실과 양쪽 입장만.
- **사건·사고**: 피해자·용의자 실명, 자극적인 묘사, 확인 안 된 추측 금지. 수사 중인 일은 "~로 알려졌어요", "경찰이 조사 중이에요".
- **연예인·개인**: 루머·열애설·사생활 추측 금지. 공식 발표만.
- **주식·코인·부동산**: 사라/팔아라 같은 투자 권유 금지. 사실과 숫자만, "투자 판단은 본인 몫" 한 줄.
- **건강·의료**: 진단·치료를 권하지 않는다. 공식 기관 안내만 전한다.
- 숫자·날짜·금액은 검색으로 확인한 것만. 확인 못 한 숫자는 쓰지 않는다.
- **이미지에 실제 사람·얼굴·정치인·연예인을 그리지 않는다.** 글자·로고·언론사 이름도 넣지 않는다.

## 구글 SEO 형식
- **slug**: 영어 소문자 3~6단어. 예) `energy-voucher-winter-apply-guide`, 아침 글은 `morning-news-2026-11-03`
- **description**: 80~120자, 핵심어 포함
- **본문 길이**: 태그 제외 1,800~2,800자 (자주 묻는 질문 포함). 너무 짧으면 애드센스에서 거절된다.
- **구성**
  1. 도입 2문단: 독자 공감 한 줄 + 오늘 글 요약
  2. `<h2>` 소제목 4~6개 (이모지로 시작)
  3. `<h2>📋 한눈에 정리</h2>` 표
  4. 마무리: 오늘 챙길 한 가지 + 댓글 질문
  5. 참고한 곳(출처)
- **faq**: 독자가 궁금해할 질문 3개와 짧은 답
- 쓸 수 있는 태그만: h2, h3, p, ul, ol, li, strong, em, table, tr, th, td, br, blockquote
- 목차·작성자 상자·유튜브 링크·모바일 스타일은 **봇이 자동으로** 넣는다.

## 이미지
- `images` 에 영어 프롬프트 **1개만** (AI 사진 무료 한도 아끼기). 사물·풍경으로 상징만 표현한다.
  예) 물가 → `"shopping basket with vegetables on a supermarket shelf"`, 날씨 → `"frosty window with winter morning sunlight"`
- `alt` 는 한글 설명 + 핵심어.

## 쿠팡 파트너스
- ⛔ 지금은 애드센스 승인 전이라 쿠팡을 넣지 않는다 (`news/data/adsense.json` approved=false). `coupang_keywords` 는 빈 목록. 승인 후에는: 생활 꿀뉴스에서 **정말 어울릴 때만** `"coupang_keywords": ["검색어"]` (예: 한파 소식 → `"핫팩"`, `"문풍지"`). 아침 종합 뉴스는 보통 빈 목록.
- 사건·사고·재난·정치 글에는 상품을 넣지 않는다 (`"coupang_keywords": []`, `"category": "없음"`).

## 파일 형식
`news/posts/YYYYMMDD-HHMM.json` (한국 시간)

```json
{
  "title": "한글 제목",
  "slug": "english-keywords",
  "description": "검색 결과용 요약",
  "labels": ["출근길뉴스", "오늘뉴스", "핵심키워드"],
  "images": [{"prompt": "english prompt", "alt": "한글 설명"}],
  "faq": [{"q": "질문", "a": "답"}],
  "coupang_keywords": [],
  "category": "없음",
  "html": "본문 HTML"
}
```

올리기 전에 `CHANNEL=news python3 blog_bot.py --dry-run` 으로 확인하고 `preview.html` 은 커밋하지 않는다.
